# AI REPORTING POLICY
Reports must distinguish:
1. Verified/measured results
2. Deterministically derived results
3. Model predictions
4. Assumptions
5. Unknown/missing data
6. Interpretation

A report generator may not create a value merely to fill an empty field.

## Phase Gate Reporting

Every active Phase ends with a Gate Report. The report must contain the acceptance
criteria and evidence for each criterion. A report without evidence is not a PASS.

The AI may prepare the Gate Report but must wait for explicit human approval before
implementation of the next Phase.

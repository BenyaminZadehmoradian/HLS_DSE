# P0 Exit Criteria — V23.2

P0 may be submitted for human Gate review only when:

- [ ] project contracts validate
- [ ] XC7Z020CLG484 is fixed and enforced
- [ ] Study IDs are unique
- [ ] Run isolation is validated
- [ ] manifest schema validates
- [ ] measurement provenance rules exist
- [ ] benchmark contract exists
- [ ] baseline reproduction contract exists
- [ ] failure/retry policy exists
- [ ] cache/reuse policy exists
- [ ] leakage policy exists
- [ ] concurrency/fairness policy exists
- [ ] P1 implementation contract exists
- [ ] no measured evidence is present without a real execution artifact
- [ ] validator exits with errors=0

P0 does not authorize P1 automatically. Human approval is required.
